# Shared libraries that binaries in the rootfs link against but we don't ship.
#
# Everything here was picked up opportunistically from the Debian builder image: the
# package's configure found an optional dependency, linked against it, and we never
# staged it. test/check-rootfs-deps.py reports these but doesn't fail on them, so that new
# regressions stand out from this existing backlog.
#
# Fixing one means either adding a package that provides the library, or configuring
# the package that wants it to build without that optional dependency. Delete the line
# once it's fixed.
#
# One thing to know before adding a package that might want one of these: a line here
# allowlists the *library*, not the consumer named in the comment beside it. A new
# package that links libcap-ng would be filed under the entry below and the build would
# pass, the binary just as broken as without this file — see the libselinux note in
# packages/iproute2/build.sh, where an entry here (since removed) nearly shipped an `ip`
# that could not start. If a package you are adding could plausibly link something on this
# list, read the binary's NEEDED rather than this check's exit status.

# ---------------------------------------------------------------------------------
# Degraded but not fatal: only the named tools break, and none are on the boot path.
# check-rootfs-deps.py names any line here that nothing in the tree it checked needs.

# util-linux setpriv.
libcap-ng.so.0
